# Ensembling Sparse Autoencoders

Project page matching the Where to Steer page and retaining the Academic Project Page Template attribution and CC BY-SA 4.0 website template license.

## Preview

Run `python3 -m http.server 8000` from the repository root and open http://localhost:8000/ensembling-saes/.

## Content

Source: https://arxiv.org/pdf/2505.16077 (v2, 11 June 2026). The page includes a paraphrased research summary, Figures 1–2, and Tables 1, 3, 4, 5, and 6, including the reported confidence intervals and method tradeoffs. The citation uses the proceedings metadata printed on page 1; page numbers are omitted because they are not supplied.

Edit `index.html` for content and `static/css/project.css` for local styling. The PDF and extracted figures are stored under `static/`. No npm build is required.

## Publish

Commit and push to the branch used by the existing GitHub Pages deployment. If Pages serves the repository root, the page will be available at https://www.sohamgadgil.com/ensembling-saes/. If it serves a generated artifact, include this directory in that artifact.

The template license does not assert a license for the paper or its figures.
